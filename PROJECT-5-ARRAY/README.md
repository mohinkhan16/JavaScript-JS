# 📊 Array Project

A simple and interactive **Array Operations Web App** built using **HTML, CSS (Bootstrap), and JavaScript**.
This project helps you understand and practice JavaScript array methods in a visual and hands-on way.

---
Live Link:-https://singular-fenglisu-8af14a.netlify.app/
---

## 🚀 Features

* Create a dynamic array by entering size
* Add elements manually
* Perform various array operations:

  * ➕ Push (Add element at end)
  * ➖ Pop (Remove last element)
  * ⬅️ Shift (Remove first element)
  * ➡️ Unshift (Add element at beginning)
  * 🔄 Reverse array
  * 🔢 Sort array
  * 🔗 Join elements
  * 🧹 Clear output
* Real-time output display

## 💡 How It Works

1. Enter the number of elements
2. Input values in generated fields
3. Click **Create Array**
4. Use buttons to perform operations
5. Output will be displayed below

---

## 📸 Example Operations

* Input: `[10, 20, 30]`
* Push → `[10, 20, 30, 40]`
* Pop → `[10, 20]`
* Reverse → `[30, 20, 10]`
* Sort → `[10, 20, 30]`
